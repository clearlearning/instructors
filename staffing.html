CLEAR Learning Instructor Staffing Dashboard

Instructor availability, roster management, and teaching history · linked to module evaluations

Connect to Shared Storage

This tool stores your instructor roster and teaching history in the same Cloudflare Worker / KV store used by the Module Evaluation Dashboard, so settings are shared automatically if you've already configured that tool in this browser. The ILT Survey ID is used to pull live evaluation scores into each instructor's teaching history.

💡 Leave the Evaluation Survey ID fields blank if you don't want eval scores linked into teaching history — everything else still works. The Instructor Availability Survey ID lets this tool pull the "Instructor Information Form" directly from SurveyMonkey on the Import tab instead of requiring a manual file export.

📝 Teaching History

Pulled directly from module evaluation responses — each cohort tagged with an Instructor, Program, Module, and Method is a class that instructor taught. Filter below to see the teaching history and scores for a given instructor, program, method, and/or module.

🔄 Sync Live from SurveyMonkey

Pulls the "Instructor Information Form" (Survey ID ) directly from SurveyMonkey — no export/upload needed. Rows are matched to existing directory entries by email (falling back to name), and if someone submitted more than once, only their most recent response is used. Nothing is written to your roster until you review the preview and click Import Selected.

🩺 Diagnose Sync Issues

If the sync above is missing instructors or leaving fields blank, click below to pull the raw question definitions and one sample response straight from the SurveyMonkey API. Copy the output and share it back so the parser can be corrected against your survey's actual structure.
