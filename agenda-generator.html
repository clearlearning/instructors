Edit opens a cohort in the single-program editor so you can add instructors, Zoom links, or fix a session; Save to batch keeps those changes for everything below. Times are Eastern for virtual cohorts and local for in-person ones.

3. Generate

Agendas: all ticked cohorts open in one print window, one agenda per page. Choose Save as PDF for a combined file, or use the Agenda button on a row for a single cohort.
Send to availability portal: new cohorts arrive in the staff dashboard as drafts, with the response date set 30 days before the first live session. Sending again later (say, after adding Zoom links) updates the same programs without losing anyone's answers.

📄 Preview & Export

How to use the .ics file: Download, then attach it to your instructor materials email. Instructors double-click the attachment in Outlook — one click to add all their sessions to their calendar. Each invite is set to start 15 minutes before the agenda time for setup and tech check. For virtual sessions, paste the Zoom link in the table above and it will appear in the invite's Location field. For NCIT Basic and Specialized programs, the testing window is added as an all-day event marked Free.
